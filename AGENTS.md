# Project guidance for AI coding assistants

- Preserve the 2023 original notebook in `archive/`; do not present archived figures as verified.
- Keep `availability_365` as availability, NEVER rename it to booked days.
- `minimum_nights` is a host stay requirement, NOT nights booked.
- Do not impute missing listing prices for analytical claims.
- Avoid regression or causal conclusions without a defensible design and evaluation.
- Run all tests and the synthetic offline demo before proposing a change.
- Do not introduce network access or package installation to runtime paths.
- Do not redistribute third-party Kaggle data or host/guest identifying details.
