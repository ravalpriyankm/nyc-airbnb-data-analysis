# Suggested contributor issues

## Good first issues
- Add alt-text descriptions for the synthetic example charts and instructions to reproduce them.
- Improve Windows PowerShell setup in README and document Python 3.13 compatibility after testing.
- Add a synthetic test for a previously unsupported *source-format* price string (do not silently guess currencies).

## Intermediate
- Add configurable, documented missing-value sensitivity reporting and compare group medians with/without filtering.
- Add separate robust quartiles and IQR plots for listed prices without silently dropping valid outliers.
- Add an HTML summary report with accessible charts and descriptive dataset provenance.

## Research
- Assess whether the Kaggle data includes fabricated values, identify assumptions, and document representativeness limitations using independently verifiable sources.
