# Synthetic analysis charts

All charts in this directory come from **fictional listing records** generated by `nyc_airbnb.demo.make_synthetic_listings`. They do not estimate NYC market prices, demand, bookings or availability.

Reproduce these images:

```bash
python -m nyc_airbnb demo --out demo-output
```

The four images illustrate counts and median **listed** prices by borough and room type. For actual data, download the original dataset separately and run `python -m nyc_airbnb analyse`.

## Accessibility

- `listings_by_borough.png`: horizontal bars showing a synthetic distribution of 80 listings across five NYC borough labels.
- `price_by_borough.png`: horizontal bars showing median fictional listed USD prices by borough label.
- `listings_by_room_type.png`: horizontal bars showing synthetic counts across three room-type labels.
- `price_by_room_type.png`: horizontal bars showing median fictional listed USD prices by room type.
