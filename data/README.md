# Data provenance and storage

## Actual data used by the original notebook

- **Name:** Airbnb Open Data, New York City listings table
- **Dataset uploader:** Arian Azmoudeh
- **Original link:** https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata
- **Referenced filename:** `Airbnb_Open_Data.csv`
- **Not provided here:** complete CSV, listing / host / guest data

The original 2023 GitHub README referred to separate listings/reviews/calendar tables from Inside Airbnb. Those tables are **not** what the uploaded notebook opens. The original data source is the Kaggle CSV linked above. The source's column definitions and dates must be checked against the actual downloaded version; do not treat the static table as current market conditions.

The cleaned Kaggle version has data-quality caveats and may contain synthetic or altered records. We don't assert that it reflects real occupancy, transactions or current prices. The upstream publisher's licence and original data provenance must be verified at source before redistributing the CSV.

## Files

- `synthetic_listings.csv` is entirely fictional, generated by `nyc_airbnb.demo.make_synthetic_listings`. Public, safe example.
- `raw/` is ignored in Git. Place a personal local copy of `Airbnb_Open_Data.csv` there.
- `processed/` is ignored in Git. Local exports deliberately exclude names, host IDs, descriptions and coordinates, but still warrant a licensing review.

See [methods](../docs/METHODS.md) for interpretation and missing-value rules.

The original analysis is also [published on the author's Kaggle profile](https://www.kaggle.com/code/priyankraval/airbnb-data-analytics-final-project-ipynb). The research dataset belongs to its uploader, not to the notebook author. See [licence/provenance notes](../docs/LICENSES_AND_PROVENANCE.md).
